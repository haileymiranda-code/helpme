# helpme

## Wedding Timeline Generator

A simple, beginner-friendly wedding day timeline generator — a single self-contained
HTML page with no dependencies.

**To use it:** open `index.html` in any web browser (just double-click the file).

Answer seven quick questions:

1. Wedding date
2. Ceremony start time
3. Reception end time
4. Whether you're doing a first look
5. Whether the ceremony and reception are at the same location
6. Number of guests
7. Special events (speeches, cake cutting, cultural traditions, send-off, and anything else)

…and it generates a realistic sample wedding day timeline — getting ready, hair and
makeup, photos, ceremony, cocktail hour, dinner, toasts, dances, cake cutting, open
dancing, last call, and send-off — in a clean table with Time, Event, and Notes
columns, plus built-in buffer time, planning tips, and warnings when the schedule
looks too tight.

The output includes a print/save-as-PDF button so you can share it with your planner,
photographer, venue, and vendors.

> **Note:** The generated timeline is a sample for planning purposes only — always
> review and adjust it with your planner, photographer, venue, and vendors.
